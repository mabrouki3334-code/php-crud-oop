# Gestion des Étudiants (PHP OOP)

Projet réalisé dans le cadre de la mise en pratique de mes compétences en développement web (BTS DSI).

## 🎯 Objectif
Mettre en place une petite application de gestion des étudiants en utilisant une architecture orientée objet (POO) et PDO pour sécuriser les requêtes SQL.

## 🛠️ Technologies utilisées
- **Langage :** PHP 8 (POO)
- **Base de données :** MySQL (PDO)
- **Front-end :** HTML5, CSS3

## ⚙️ Installation
1. Cloner le projet dans le dossier `htdocs` de XAMPP.
2. Importer le fichier `db.sql` dans phpMyAdmin.
3. Vérifier les paramètres de connexion dans `config.php`.
4. Ouvrir `http://localhost/php-crud-oop`.

## ✨ Fonctionnalités
- Ajout d'un étudiant avec sa filière.
- Liste des étudiants.
- Suppression avec confirmation.
